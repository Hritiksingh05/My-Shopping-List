# My-Shopping-List
SmartCart is a modern, responsive shopping list manager built with AngularJS, featuring a glassmorphism UI, local storage persistence, and real-time search filtering. It allows users to easily add, remove, and mark items as purchased — all with smooth animations and an elegant design.
# 🛒 SmartCart – A Modern Shopping List Manager

SmartCart is a sleek and interactive **shopping list web app** built using **AngularJS**, designed to make managing your daily shopping easy and visually satisfying.

✨ _Add, mark, search, and save your shopping items — with style!_

---

## 🚀 Features

✅ **Add & Remove Items** – Quickly add new products or remove old ones.  
✅ **Mark as Purchased** – Strike-through completed items with one click.  
✅ **Search Filter** – Instantly search through your list.  
✅ **Persistent Storage** – Your list stays saved even after refreshing (via LocalStorage).  
✅ **Clear All Button** – Remove everything in one go.  
✅ **Modern UI** – Glassmorphism design with smooth animations.  
✅ **Responsive Layout** – Works beautifully on phones, tablets, and desktops.

---

## 🧠 Tech Stack

- **Frontend Framework:** AngularJS (v1.8.2)
- **Language:** HTML5, CSS3, JavaScript (ES5)
- **Storage:** LocalStorage API
- **Design:** Modern glassmorphism + gradient UI
